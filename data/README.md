# データの説明

| ファイル | 内容 |
|---|---|
| `map.json` | 生成された地図(`npm run build-map`)。ステート(1939年の補正で移したものは `formerOwner` にもとの国)、陸路・海路、首都の既定値、勝利条件の都市 |
| `importance.json` | 重要度マップ(地域ごとのステートの目標面積)と、残す小島 |
| `important-cities.json` | 重要都市26地点の当時の地名、概略座標、1939年所有国、陥落・奪還判定の基準国。`map.json.importantCities` に州IDと描画座標を生成。勝利条件には含めない |
| `border-fixes.json` | 1938年の国境を1939年9月に近づける修正、国の分割(`countrySplits`: オランダ領東インド)、首都・都市の座標、本土の定義 |
| `sea-routes.manual.json` | 手動の海路 |
| `sea-zones.json` | 海の戦域(名前と代表点)、運河による接続 |
| `presets/historical.json` | 史実プリセット |
| `raw/` | 元データ(`npm run fetch-sources` で取得。リポジトリには含めない) |

## 史実プリセット(`presets/historical.json`)

**すべての数値は近似値で、ゲームの調整用。** 実際の経済統計そのものではない。

### 陸軍生産力(`industry`、相対指数、米国 = 100)

陸軍の年間の伸びの基準(陸軍生産力 × 政治安定性 × マスク)。画面の「工業力」は 陸軍生産力 + 海軍生産力。
計算は `notes/derive-production.py`(`--apply` でこのファイルに書き込む)。

- **主要7か国(出典あり)**: 1938年のGDP(Harrison 1998、10億1990年国際ドル: 米 800、英 284、独 351、ソ 359、仏 186、日 169、伊 141)と、
  1938年の世界の工業生産に占める割合(Bairoch、Kennedy『大国の興亡』の引用: 米 31.4%、英 10.7%、独 12.7%、ソ 9.0%、仏 4.4%、日 5.2%、伊 2.8%)を
  それぞれ米国 = 100 に直して平均し、植民地のGDP(Harrison: 英 285、仏 49、日 約63、伊 3)を半分の重みで足した
  (植民地は軍需工業が小さいため)。結果: 米 100、英 52.6、独 42.2、ソ 36.8、日 22.8、仏 21.7、伊 13.5。
  工業生産の割合は推計によって差が大きい(Hillmann 1952 では米 35.1%、ソ 14.1%、独 11.4%、英 9.4%)。
- **ほかの国(推定)**: 1938年のGDP × 工業化の係数。GDP は中国 320.5・ルーマニア 24・ハンガリー 24・ブルガリア 10 が Harrison、
  それ以外は Maddison の値の**記憶による概算**(要確認)。係数は**仮定**: 工業国 0.8(蘭・白・瑞典・スイス・丁・諾・加・豪・NZ)、
  中間 0.6(ハンガリー・フィンランド・南ア・アルゼンチン・チリ・ウルグアイ・アイルランド・バルト)、農業国 0.5(ポーランド・スペイン・
  ポルトガル・ギリシャ・ユーゴ・トルコ・ルーマニア・ブルガリア・スロバキア・中南米の多く)、植民地・ごく農業的 0.3(蘭印・イラン・タイ)、
  中国 0.2(軍需工業がごく小さい)。値は `notes/derive-production.py` の表。載っていない小国は以前の推測値のまま。
- 以前の値(Kennedy の「1937年の相対的戦争潜在力」の記憶による換算: 英 24、仏 10、日 8、伊 6 など)は、GDP・工業生産の資料と比べて
  英仏日伊が低すぎたので置き換えた(ユーザーの指示)。

### 海軍生産力(`shipbuilding`、海軍力が毎年 海軍生産力 × 政治安定性 ずつ増える)

ユーザーの選択で、**海軍生産力は大戦中の建造実績**に、**開戦時の海軍力は1939年の艦隊の大きさ**に合わせる(下)。
1単位 = 12.35千トン(英海軍1939年 1,593千トン = 129、以前の英国の開戦時の値に合わせた尺度)。

- 1939〜45年に完成した艦艇の数(艦種別、Wikipedia「Naval history of World War II」の表)に典型的な排水量(正規空母 25、護衛空母 10、
  戦艦 40、巡洋艦 10、駆逐艦 2、潜水艦 1(Uボート 0.8)千トン)を掛けた**推定**の建造トン数を、建造していた年数で割った:
  米 約915、英 約295、日 約231、独 約171(大半がUボート)、伊 約70、ソ 約50(推定)、仏 約60(1939〜40年、推定)、加 約50(護衛艦、推定)千トン/年。
- これを単位に直し、政治安定性で割り戻した(実際の伸びが 海軍生産力 × 安定性 になるため): 米 82.3、英 26.5、日 20.8、独 14.6、伊 8.1、
  仏 8.1、ソ 5.1、加 4.8。
- 日本を英国の同等〜1.5倍にするという以前の指示は、ユーザーの判断で外した(資料どおり英国より小さい)。
- ほかの国は以前の推測値のまま(内陸国は 0)。

### 開戦時の海軍力(`navy`)

1939年の艦隊の総トン数を上の単位に直した値。以前の「海軍生産力 × 安定性 × 8年(米国 2年)」の決め方は、ユーザーの判断でやめた
(戦時の建造実績に合わせた海軍生産力から逆算すると、ドイツの開戦時の艦隊が大きくなりすぎるため)。値のない国だけ、従来の決め方を使う。

| 国 | 1939年の艦隊(千トン) | 開戦時の海軍力 | 根拠 |
|---|---|---|---|
| 英国 | 1,593 | 129 | naval-encyclopedia.com の集計(英連邦を含む) |
| 日本 | 1,250 | 101 | 同上 |
| 米国 | 約1,300 | 105 | 推定(条約の上限と艦艇の構成から) |
| フランス | 約640 | 52 | 同サイトの艦種別の値(潜水艦・その他は推定で補った) |
| イタリア | 約550 | 45 | 推定 |
| ソ連 | 402 | 33 | naval-encyclopedia.com |
| ドイツ | 約250 | 20 | 推定(大型艦8・駆逐艦22・Uボート57 から) |

ほかの国(スペイン・アルゼンチン 各約110、スウェーデン 約90、蘭印 約55、豪州 約60 など)は**推定**。値は `notes/derive-production.py`。

### 上陸の制限(日本本土)

`landingRestrictions` の `protect` で、日本本土(本州・九州・四国・北海道の周辺、31ステート)への上陸を、
沖縄(琉球諸島のステート)と硫黄島(伊豆・小笠原・硫黄島をまとめたステート)が両方とも枢軸の手を離れるまで禁止している。
ステートIDは `npm run update-preset-ids` が地図から求める(沖縄・硫黄島は座標を含むステート)。

### 上陸の制限(イタリア)

`landingRestrictions` で、イタリア本土(本来のイタリアの本土ステート)への上陸を、北アフリカに枢軸国のステートがある間は禁止している。
北アフリカの範囲(現在の地図では308ステート: 仏領158、伊領リビア77、英領エジプト68、西領モロッコ5)は
`npm run update-preset-ids` が地図から求める(アルジェリアのステートから陸続きでたどり、北緯21.8°以北・東経34.2°以西に限る)。

### 政治安定性(0.0〜1.0)

**すべて推測。** 出典はない。1939年時点の政情(内戦や分裂、体制の動員力)についての一般的な理解から付けた。
例: 中国 0.4(国共の分裂、軍閥)、フランス 0.6(政局の不安定)、ドイツ 0.95(総動員体制)、ルーマニア・ユーゴスラビア 0.5。

### 陣営と参戦日

史実のおおよその日付(各国の宣戦布告日)。同じ月の近い日付はまとめたものがある(`note` に記載)。
自治領(カナダ、豪州、ニュージーランド、南アフリカ)の宣戦日は個別に入れた。
入れていないもの: ソ連のポーランド侵攻・冬戦争・バルト三国併合、英ソのイラン進駐、中南米諸国の参戦、
イタリアの1943年の降伏と寝返り。

### 乱数シード

既定のシードは 1948。独ソ戦の奇襲と自由フランスを加えて再調整した後に、連合国が勝つ典型的な展開(ポーランド降伏1939年9月、仏降伏1940年6月7日、パリを自由フランスが1944年12月に奪還、ベルリン陥落1945年4月13日、伊降伏1945年5月4日、東京陥落による1946年1月終結)になるものを `scripts/seed-scan.ts` で選んだ。モスクワは1942年12月に一度陥落する(全体でも約8割の回で陥落する。既知の課題)。

### 首都

`map.json` の既定値を使う(`border-fixes.json` の `capitals` の座標を含むステート)。
中国の首都は1939年時点の臨時首都・重慶とした。

### 占領不可ステート(マジノ線)

仏独国境に接するフランス本土のステートを `stateOverrides` で `invulnerable: true` にしている(現在の地図では3ステート)。
地図を作り直すとステートIDが変わるので、`npm run update-preset-ids` で更新する。
