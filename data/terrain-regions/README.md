# Terrain region boundaries

`ukraine.geojson` is the unmodified simplified ADM0 boundary distributed by geoBoundaries, UKR-ADM0-60985579
(boundary year represented: 2017; geoBoundaries build: 2023-12-12; commit 9469f09).

- Source metadata: https://www.geoboundaries.org/api/current/gbOpen/UKR/ADM0/
- Download: https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/UKR/ADM0/geoBoundaries-UKR-ADM0_simplified.geojson
- Original boundary sources: OpenStreetMap, Wambacher; © OpenStreetMap contributors.
- Boundary data license: Open Data Commons Open Database License 1.0 (ODbL): https://opendatacommons.org/licenses/odbl/1-0/
- OpenStreetMap attribution and license information: https://www.openstreetmap.org/copyright

This polygon is used only to assign terrain difficulty to existing map states. Centres inside the boundary and
state polygons overlapping it are included, so border states such as the one containing Izmail are not missed.
It does not change the simulator's 1939 ownership, borders, state IDs, capitals or projection.
