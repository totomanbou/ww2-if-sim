# 第二次世界大戦 IF観察シミュレーター

1939年9月1日から始まる第二次世界大戦を、国ごとの条件を変えて「もしも」を観察するブラウザアプリです。
プレイヤーは開戦前の条件を決めるだけで、あとは戦争の推移を見守ります。ブラウザだけで動き、サーバーは要りません。

**ブラウザで遊ぶ: https://totomanbou.github.io/ww2-if-sim/**

> 結果は簡略化したモデルと乱数によるもので、史実の再現や、特定の国・人物・思想の評価を意図したものではありません。

## できること

- **条件を変える**: 国ごとに工業力・造船力・政治安定性と陣営(枢軸国・連合国・中立国)を変えられます。
  陣営を変えると宣戦布告の組み合わせも作り直されます。植民地・自治領は宗主国の陣営に従います。
- **観察する**: 地図上で前線が動き、宣戦布告・首都や重要都市の陥落・降伏がニュースとして流れます。
  再生速度の変更と一時停止ができます。
  地図は東西につながったメルカトル図法で、太平洋もそのまま見渡せます。
- **結果を見る**: 勝利陣営と終結日、犠牲者数、陣営ごとの陸軍・海軍・工業力の推移、年表を表示します。
  同じ条件のまま乱数シードだけを変えて、何度でもやり直せます。
- **条件を保存する**: 編集した条件と乱数シードを JSON ファイルに保存・読み込みできます。

## 遊び方

1. 起動するとセットアップ画面が開きます。史実の1939年9月の状態が読み込まれています。
2. 地図をクリックするか右側の一覧から国を選び、値や陣営を変えます(変えなくても構いません)。
3. 「開始」を押すと観察画面に移り、戦争が自動で進みます。
   - スペースキーで一時停止・再開、ホイールでズーム、ドラッグで移動、ダブルクリックで全体表示。
   - スマートフォン・タブレットでは、2本指のピンチでズーム、1本指のドラッグで移動、ダブルタップで全体表示。
4. 戦争が終わると「結果を見る」で結果画面に移ります。

### 勝利条件

- **連合国**: 日本・ドイツ・イタリアをすべて降伏させる。
- **枢軸国**: 条件A(ロンドン・モスクワ・ホノルルをすべて占領)か、
  条件B(モスクワを占領し、パリと重慶を保持したまま156週=3年続ける)を満たす。
- 陣営を入れ替えた場合は、対象都市のもとの国の今の陣営で対象を切り替えます。連合国は枢軸側の対象国すべての降伏が必要です。
- どちらも満たさないまま打ち切り日(1951年1月1日)に達すると膠着です。

細かい規則(戦線と兵力の配分、海軍と上陸、降伏の条件、季節と地形など)は
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) にあります。

## 動かし方

[Node.js](https://nodejs.org/) 20 以上が必要です。

```bash
npm install
```

```bash
npm run dev
```

表示された URL(通常は http://localhost:5173 )をブラウザで開きます。

公開用の静的ファイルを作るときは次のとおりです。`dist/` の中身をそのまま静的ホスティング
(GitHub Pages など)に置けば動きます(相対パスで作るので、サブディレクトリでも動きます)。

```bash
npm run build
```

テストは `npm test` で実行できます。地図データ `data/map.json` は同梱しているので、地図を作り直すとき以外は
元データの取得(`npm run fetch-sources`)と地図の生成(`npm run build-map`)は不要です。
開発用のコマンドと設計の詳細は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を見てください。

## 使用データと出典

- **[historical-basemaps](https://github.com/aourednik/historical-basemaps)**(André Ourednik)の `world_1938`。
  国境と所有国の元データで、`data/map.json` はこれから作った派生データです。GPL-3.0。
- **[Natural Earth](https://www.naturalearthdata.com/)** の陸地・小島・地域・河川のデータ。パブリックドメイン。
- **[geoBoundaries](https://www.geoboundaries.org/)** のウクライナの境界(地形難易度の指定にだけ使用)。
  ODbL 1.0、境界の元データは © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)。
  詳細は [data/terrain-regions/README.md](data/terrain-regions/README.md)。
